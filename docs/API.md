# API

Base URL: `http://127.0.0.1:4317`

`GET /health` returns only:

```json
{ "ok": true }
```

If `MOBILE_AUTH_TOKEN` is set, include this header on generation, feedback, and settings endpoints:

```http
Authorization: Bearer <token>
```

## Import X Archive

`POST /api/import/x-archive`

```json
{
  "archivePath": "/absolute/path/to/twitter-archive.zip"
}
```

Alternative inputs:

```json
{ "archiveBase64": "..." }
```

```json
{ "tweetsJsText": "window.YTD.tweets.part0 = [...]" }
```

## Generate Post

`POST /api/generate/post`

```json
{
  "topic": "What I learned shipping a Chrome extension",
  "goal": "authentic",
  "length": "short",
  "instructions": "Make it practical and not hypey."
}
```

## Generate Comment

`POST /api/generate/comment`

```json
{
  "sourcePost": {
    "id": "123",
    "author": "someone",
    "text": "Original X post text"
  },
  "angle": "Add a concise practical caveat",
  "instructions": "Do not be promotional."
}
```

For the iPhone keyboard, `sourcePost.text` must be manually supplied context. The backend does not read the X screen or call the X API.

## Generate Rewrite

`POST /api/generate/rewrite`

```json
{
  "text": "rough draft already typed in the composer",
  "kind": "post",
  "instructions": "Make it clearer and less hypey.",
  "mode": "standard",
  "model": "standard"
}
```

Fields:

- `text`: required non-empty draft text.
- `kind`: `post` or `comment`.
- `instructions`: optional rewrite guidance.
- `mode`: optional `standard` or `cheap`.
- `model`: optional `standard` or `advanced`.

Response uses the same draft envelope as post/comment generation:

```json
{
  "data": {
    "suggestions": [
      {
        "id": "uuid",
        "text": "Rewritten draft",
        "rationale": "Why this works",
        "confidence": 0.84
      }
    ]
  },
  "meta": {
    "cached": false,
    "model": "MiniMaxAI/MiniMax-M3",
    "estimatedCostUsd": 0,
    "inputTokens": 100,
    "outputTokens": 80
  }
}
```

## Score Visible Posts

`POST /api/score/visible-posts`

```json
{
  "posts": [
    {
      "id": "123",
      "author": "someone",
      "text": "Visible post text",
      "url": "https://x.com/someone/status/123"
    }
  ]
}
```

Recommendations are limited to `reply`, `quote idea`, `save for later`, or `skip`.

## Feedback

`POST /api/feedback`

```json
{
  "suggestionId": "uuid",
  "kind": "comment",
  "decision": "edited",
  "originalText": "Draft generated by the model",
  "finalText": "What you actually used",
  "context": {
    "sourcePostId": "123"
  }
}
```

Accepted and edited `finalText` can be added back into local examples for future personalization.

## Settings

`GET /api/settings`

`PUT /api/settings`

These routes are protected by `MOBILE_AUTH_TOKEN` when configured.
