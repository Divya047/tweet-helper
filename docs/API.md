# API

Base URL: `http://127.0.0.1:4317`

## Import X Archive

`POST /api/import/x-archive`

```json
{
  "archivePath": "/absolute/path/to/twitter-archive.zip"
}
```

Alternative inputs:

```json
{ "archiveBase64": "..." }
```

```json
{ "tweetsJsText": "window.YTD.tweets.part0 = [...]" }
```

## Generate Post

`POST /api/generate/post`

```json
{
  "topic": "What I learned shipping a Chrome extension",
  "goal": "authentic",
  "length": "short",
  "instructions": "Make it practical and not hypey."
}
```

## Generate Comment

`POST /api/generate/comment`

```json
{
  "sourcePost": {
    "id": "123",
    "author": "someone",
    "text": "Original X post text"
  },
  "angle": "Add a concise practical caveat",
  "instructions": "Do not be promotional."
}
```

## Score Visible Posts

`POST /api/score/visible-posts`

```json
{
  "posts": [
    {
      "id": "123",
      "author": "someone",
      "text": "Visible post text",
      "url": "https://x.com/someone/status/123"
    }
  ]
}
```

Recommendations are limited to `reply`, `quote idea`, `save for later`, or `skip`.

## Feedback

`POST /api/feedback`

```json
{
  "suggestionId": "uuid",
  "kind": "comment",
  "decision": "edited",
  "originalText": "Draft generated by the model",
  "finalText": "What you actually used",
  "context": {
    "sourcePostId": "123"
  }
}
```

Accepted and edited `finalText` can be added back into local examples for future personalization.
